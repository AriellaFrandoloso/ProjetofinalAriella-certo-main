# ProjetoFinalAriella — Mitologia Grega

Site desenvolvido com Bootstrap 5.3.

## Como abrir
1. Extraia a pasta do ZIP.
2. Abra a pasta no Visual Studio Code.
3. Execute `index.html` com Live Server.

## Páginas
- `html/index.html`: página inicial.
- `html/oquee.html`: explicação sobre mitologia grega.
- `html/origem.html`: origem e história.
- `html/deuses.html`: principais deuses.
- `html/questionario.html`: formulário de dúvidas.

## Questionário
O formulário segue os campos e a sequência do questionário do projetoFinalThauan: nome completo, idade, e-mail, como conheceu o site e dúvida. A validação verifica nome e sobrenome, idade entre 4 e 110 anos, e-mail, seleção de uma opção e texto com pelo menos 10 caracteres. Depois da validação, abre um modal de confirmação.

Os arquivos do projeto original foram mantidos. O formulário é demonstrativo e não envia nem armazena dados em um servidor.
